# PermissionLab

An Android app project for exploring and managing application permissions.

## Overview
PermissionLab aims to present app-permission information in a clear interface, making it easier to inspect permission-related details on an Android device.

## Project
- Platform: Android
- Language: Java

## Getting started
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and build the app.
4. Install on a test device and review the permissions Android makes available to the app.

## Android notes
Permission visibility and management capabilities vary by Android version. The app can only perform actions allowed by the operating system and granted access.

## Status
